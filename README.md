# Akill-ev-enerji-tuketim-tahmini-projesi-Marmara-Uni
Akıllı ev enerji tüketim tahmini projesini geliştirmek için bu repoda çalışacağız. Bu proje ile beraber dün ve bugün olarak kullanılan enerji miktarı hesaplanıp yarın için kullanılacak enerji miktarını hesaplayabiliceğiz. Bu sayede gelecekte ihtiyaç olabilicek enerjiyi daha tasarruflu kullanmaya başlayabiliceğiz.
